Constructors:
- It is a special method which will invoked automatically when an object of the class is created.
- It is used to initilize the values to the members of the class.

Rules:
- Same name as classname.
- It doesn't have return types even void also.
- Called automatically via "new" keyword.
- If a class is not having any user-defined constructor system/program will create it's own constructor.

Types of constructors:

- Default : Here we don't have parameters.
	- User-Defined
	- System-Defined
- Parameterised: with parameters.
Note: A class can have any number of constructors.It must be overloaded. It must be differ in number of parameters, type of parameters or order of parameters.This is also known as Constructor Overloading.

Constructor Chaining : this(...) is constructor chaining — avoids duplicating initialization logic across constructors. This is a favorite "write clean code"

- Copy:
	- A constructor used to copy one class data into another class.
	- We can create copy constructor with atleast one parameter of class type.
---------------------------------------------------------------------------------------------------------
- Static Constructor:
	- Static means something belongs to the type itself, not any individual object created from that type.
	- Static members can't be called with instances/objects.
	- It is maintianed a single memory across the class level not the object level.
	- A constructor which will be created with static keyword, and it is initialize only static members.
	- Static constructors will not allowed to have the access modifiers.
	- A static constructor must be parameter less.
- Private Contructor:
	- A constructor which will be created with private access modifier.
	- It is used to stop to create the object of the class from one to another.
	- singleton design pattern.


Destructors:
- It is a special method that runs when the object is about to be destoryed, it is mainly used to deallocate the memory.

Rules:
- It start with ~
- No access modfiers, no parameters, no return types.
- can't be overloaded - so we can have only one.
- It automatically execute when the class unload from memory.
